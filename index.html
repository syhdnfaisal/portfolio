Recent Project

Dashboard Monitoring Transaction

A transaction monitoring dashboard designed to help the application support team monitor transaction activity in real time, detect discrepancies, and ensure optimal system performance. This dashboard displays transaction data centrally with informative visualizations such as branch name, closing date, report total, and information about any discrepancies. Users can filter by date for easier analysis.

The application is built using Node.js and Express.js to handle the API, data processing, and database integration. The backend is designed with a RESTful API architecture for easy development and scalability.

POS System

I developed a web-based Point of Sale (POS) system designed to facilitate efficient, fast, and integrated sales transaction processing. This system allows users to manage sales, products, and transaction reports in one easy-to-use platform.

On the backend, the application was built using Laravel, which implements an MVC architecture to keep the code structure clean and easy to develop. To speed up the creation of the admin dashboard, I utilized Filament, which allows for efficient data management with a modern and intuitive interface.
